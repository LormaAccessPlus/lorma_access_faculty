## Step-by-Step Instructions

### Step 1: Navigate to Grade Matrix
1. Login to the system
2. Go to "Grading System" in sidebar
3. Select "Grade Matrix"
4. Choose your subject

### Step 2: Click Export Button
- Look for the orange "Export Grades" button
- Located in the top right corner
- Next to "Grade Sync" button

### Step 3: Choose Export Type
- Modal will appear with 3 options
- Click on your desired export type
- For term-based, select specific term

### Step 4: Download PDF
- PDF generates automatically
- Downloads to your default folder
- Filename format: `SubjectCode_ExportType.pdf`

---

## File Naming Convention

- **Activities:** `CS101_Activities_Exam.pdf`
- **PP Grades:** `CS101_Grades_PP.pdf`
- **Term:** `CS101_Prelim_Grades.pdf`

## Tips & Best Practices

### ✅ Do:
- Export after finalizing grades
- Check data before exporting
- Keep PDFs for records
- Use appropriate export type for purpose

### ⚠️ Note:
- PDFs are read-only
- Cannot edit after generation
- Re-export if grades change
- Each export is timestamped

---

## Troubleshooting

### PDF Not Downloading?
- Check browser download settings
- Allow pop-ups for the site
- Try different browser

### Missing Data in PDF?
- Ensure grades are entered
- Check student mappings
- Verify activities exist

### Wrong Information?
- Update grades in system
- Re-export PDF
- Check subject selection
